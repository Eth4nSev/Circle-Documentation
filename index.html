Circle — Complete Feature List

Here is the consolidated feature set we've established throughout this conversation, including the latest changes and removing features you've decided against.

---

01

1. Core Concept

Circle is a privacy-focused social media app designed around sharing with people you intentionally choose.

Core principles:

  • Privacy-first
  • No ads
  • No stories
  • No Shorts/Reels-style entertainment feed
  • No algorithmic entertainment feed
  • Core social features remain free
  • Small, intentional communities

Circle is not being merged with LetsChat.

---

02

2. Accounts & Profiles

Account privacy

Accounts can have different access levels:

  • Normal account
  • Private account where followers require approval
  • Invite-only account

Invite-only accounts

When an account is invite-only:

  • It does not appear in search.
  • Other users cannot simply discover the account.
  • The user needs an invite link.
  • Following/access requires accepting the invitation.

Profiles

Profiles include things such as:

  • Profile picture
  • Username
  • Display name
  • Bio
  • Profile background
  • Privacy settings

Profile backgrounds

Users can customize the background of their profile screen.

The background can eventually support things like:

  • Colors
  • Gradients
  • Images
  • Other customization options

The profile background is a personal UI preference, rather than something that changes the underlying account for everyone.

3. Posts

Users can create posts containing:

  • Photos
  • Videos
  • Text
  • Captions
  • Edited media

When creating a post, users can choose:

  • Whether comments are enabled
  • Whether emoji reactions are enabled
  • Whether sharing is enabled

Post editing

Circle will have editing tools including:

  • Basic editing
  • Filters
  • Effects
  • Premium filters/effects
  • Future AI editing tools

Free premium-effect rotation

Free users can periodically access premium filters/effects.

The current idea:

Every two weeks, a different premium filter/effect becomes available to Free users.

4. Post Viewing

Posts use a GlassView-based UI.

The general visual structure is:

Custom background → translucent GlassView → post

This allows the user's Circle/profile background to visually show through the post interface.

Post interactions include:

  • Like
  • Comment
  • Emoji reaction
  • Share
  • More options

05

5. Emoji Reactions

Users can react to posts with emojis.

When tapping the emoji reaction option:

  • The phone's emoji keyboard opens.
  • The user selects an emoji.
  • The emoji becomes a reaction.

Instead of showing every reaction directly on the post, the post can show:

Most-used emoji + total reaction count

For example:

😂 47

Users can still open the reactions to see more information.

06

6. Comments

Posts can have comments.

When creating a post, the author can choose:

**Allow comments**

If disabled, other users cannot comment on that post.

---

07

7. Post Sharing

Posts can have sharing enabled or disabled.

When sharing is enabled, users can share a post with a Circle.

Privacy restrictions

A post cannot bypass its privacy settings.

For example, if someone tries to share a post with somebody who:

  • Doesn't follow the original poster
  • Isn't in the appropriate Circle
  • Doesn't have permission to view it

the share won't work.

Circle sharing

A shared post can appear inside the Circle's conversation/chat.

---

08

8. Post Downloading

The Download Post option is only available to the original poster.

Other users cannot download the post through Circle's built-in download function.

09

9. Post Reporting

Posts have a Report Post option inside the post's three-dot menu.

Users can report a post by selecting:

  • Reason for reporting
  • Optional report message

The report contains the reported post and the report information.

The moderation system is designed so that the reported user doesn't see who reported them.

10. Circles

Circles are the central feature of the app.

They allow users to organize people into intentional groups.

Examples:

  • Family
  • Closest Friends
  • School
  • Gaming
  • Sports
  • Projects
  • Trips

You can create an unlimited number of Circles.

Important change

Public Circles have been removed.

Circles are no longer intended to become thousands-member public communities.

11

11. Circle Member Limit

Each Circle has a maximum of:

**50 members**

This reinforces the idea that Circles are small, intentional communities.

A full Circle cannot accept additional members until someone leaves or is removed.

14. Circle Roles

There are three Circle roles:

Admin

The highest-level Circle role.

Can:

  • Edit Circle
  • Manage members
  • Manage Circle settings
  • Manage permissions
  • Manage invitations
  • Promote/demote Managers
  • Enable/disable Circle Chat
  • Configure advanced circle controls

Manager

Can do essentially everything an Admin can do except enable/disable Circle Chat.

Member

Normal Circle participant.

Can:

  • View Circle posts
  • Create posts
  • Comment
  • React
  • Participate in chat
  • Customize their personal Circle experience
  • Mute/block Circle Chat
  • Take part in Circle activity

18. Circle Chat

A Circle can optionally have its own chat.

When creating a Circle, the user can choose whether to enable chat.

Chat can later be enabled/disabled through Circle settings by the appropriate administrator.

Chat content

Users can send:

  • Text
  • Images
  • Emoji reactions

The chat is intentionally simple and isn't heavily customizable.

Chat appearance

The chat uses the Circle's chosen accent/color.

Individual chat blocking

Every member can independently block the Circle Chat for themselves.

This doesn't disable chat for everyone else.

22. No Public Circles

The Public Circles idea was explicitly removed.

There will not be:

  • Public town Circles
  • Public city Circles
  • Public county Circles
  • Public interest Circles
  • Thousands-member public communities
  • Public Circle discovery

This keeps Circles focused on actual relationships and intentionally selected groups.

24. AI Post Moderation

A future AI moderation system can automatically check posts.

Proposed flow:

User presses Post
↓
Temporary upload
↓
AI moderation
↓
Approved?
↙         ↘
Yes         No
↓            ↓
Publish     Return to editor

If approved

The post continues through the normal publishing process.

If rejected

The user is returned to the post editing screen and receives a message explaining that the post wasn't approved because it violates Circle's Terms/Community Guidelines.

The AI should eventually be able to detect things such as:

  • Spam
  • Harassment
  • Hate content
  • Threats
  • Explicit content
  • Other prohibited content

Borderline cases can be sent to human moderation instead of automatically rejecting them.

26. Human Moderation

Circle will have a reporting/moderation system.

Reports contain:

  • Report reason
  • Report message
  • Reported post

The reporter's identity isn't shown to the reported user.

Moderation dashboard

You can have an internal Circle moderation website/dashboard.

Potential actions:

  • Ignore
  • Remove post
  • Warning
  • Suspend for 1 week
  • Suspend for 1 month
  • Permanent ban eventually

Suspension

When a user is suspended:

  • They cannot post during the suspension.
  • The original poster receives an email explaining the reason and suspension length.
  • The reporter receives a thank-you/confirmation email.

The reporter should not necessarily be told exactly what punishment was issued, preserving privacy around moderation decisions.

27. Privacy Architecture

A major design principle is:

**Store as much as reasonably possible on-device.**

The app should use a local-first approach.

Local data

Potentially stored on-device:

  • Draft posts
  • Post editor state
  • Cached feed data
  • Recently viewed content
  • Circle ordering
  • Pinned Circles
  • Grid/List preference
  • Circle backgrounds

Supabase

Supabase stores information that needs to be shared or synchronized between users, such as:

  • Accounts
  • Profiles
  • Followers
  • Circle memberships
  • Posts
  • Comments
  • Likes
  • Emoji reactions
  • Circle information
  • Circle roles

The principle is:

**Your device stores your personal experience; Supabase stores the shared social world.**

28. Supabase Backend

Circle is being built using Supabase.

Potential Supabase services:

  • PostgreSQL database
  • Supabase Auth
  • Supabase Storage
  • Row Level Security
  • Edge Functions
  • Realtime features for chat/notifications

Security

Supabase Row Level Security should enforce things such as:

  • Users can only modify their own data.
  • Users can't access private posts they aren't authorized to view.
  • Only Circle members can access Circle content.
  • Only admins can manage sensitive Circle controls.

29. Authentication

Supabase Auth handles accounts and authentication.

The app shouldn't store passwords in its own user table.

Potential login methods include the authentication options you've previously been considering, including Apple/email-based authentication.

30. No Stories

Circle explicitly does not have Stories.

This is intentional.

The app focuses on persistent posts rather than temporary content designed to encourage frequent checking.

31. No Reels/Shorts-Style Feed

Circle will not have an infinite vertical video feed.

Videos are simply another type of post.

There will not be:

  • Reels-style interface
  • Shorts-style interface
  • Swipe-to-next-video entertainment loop
  • "For You" entertainment feed

The philosophy is:

**Circle is for sharing with people you care about, not maximizing screen time.**

35. Business Philosophy

Circle's monetization is intentionally focused on optional features rather than access to the social network itself.

The fundamental experience isn't supposed to be:

"Pay us to use Circle."

It's:

"Circle is free; pay if you want premium creative tools or want to support the project."

36. Circle's Overall Identity

The features collectively point toward a very specific product:

Circle is:

  • Private
  • Relationship-focused
  • Ad-free
  • Small-community oriented
  • Customizable
  • Privacy-conscious
  • Moderated
  • Local-first where possible

Circle is not:

  • A TikTok clone
  • An Instagram Stories clone
  • A public forum
  • A giant community platform
  • An entertainment feed
  • An ad-driven social network

The strongest core loop is essentially:

People you know → Circles → Posts → Conversations → Reactions → Sharing

That is the current version of Circle based on everything we've established in this chat.

37. Additional Features Confirmed From Circle Documentation

The following features were present in the Circle product document but were missing or not fully represented in the consolidated feature list above.

Features Only Present in the App Repository

  • Biometric private dashboard security: Face ID / local authentication is configured for a private dashboard flow and a privacy/security settings area.
  • Direct Messages: The app includes a dedicated DM interface and message flow separate from Circle chat.
  • Account settings center: The app contains concrete Account, Privacy & Security, Appearance, and Circles settings screens.
  • Follower/following social graph: Relationship flows, mutual-friend discovery, and profile interaction logic are implemented in the app.
  • Profile onboarding gate: The app redirects users through profile setup and verifies session/profile completeness before allowing access.
  • Service outage handling: There is an explicit outage state for backend/service restrictions and graceful degradation for downtime.
  • Public-vs-Circle posting: Posting includes a Public option and a Circle-specific audience selector, with privacy-aware sharing behavior.

Design & Platform

  • Circle supports Dark Mode.
  • The primary visual theme is black and white.
  • The application accent color is `#17b3da`.
  • The interface should remain minimal, simple, and calm.

Circle Creation

When creating a Circle, the user can configure:

  • Circle name
  • Circle color
  • Circle icon
  • Whether Circle Chat is enabled

Circle icons can use:

  • A photo
  • An emoji
  • A monogram

Members can be added by:

  • Selecting mutual friends
  • Creating an invite link

Circle Personal Customization

Each member can independently customize how a Circle appears on their own device, including the Circle's:

  • Name
  • Photo/icon
  • Color

These personal customizations do not change the Circle's appearance for other members.

Profile Privacy

The documented profile privacy model includes:

  • Public
  • Private
  • Requires approval for followers
  • Hidden

Hidden profiles:

  • Are hidden from search.
  • Can be accessed through an invitation mechanism.
  • Can require invite-link-based approval.

Profiles intentionally avoid follower counts and other popularity metrics.

Posts

Posts can contain:

  • Images
  • Videos
  • Text
  • Captions

When creating a post, the author can choose who can see it:

  • Publicly
  • One or more Circles

The author can also configure:

  • Comments
  • Emoji reactions
  • Public like count
  • Sharing

Post Sharing

The documented sharing options include:

  • Sharing with Circles when the post is public
  • Copying a post link

Sharing must continue to respect the original post's privacy permissions.

Feed

The home feed is chronological rather than algorithmically ranked.

It contains new posts from:

  • The user's Circles
  • People the user follows

There is no engagement-based ranking system.

Privacy & Data Collection

Circle's privacy architecture includes these explicit principles:

  • No advertisements
  • Minimal data collection
  • No selling user information
  • Clear privacy settings
  • User-controlled information
  • Transparent privacy policies

The app should store more data on the user's device whenever reasonably possible to reduce centralized storage and give users greater control.

Transport & Credential Security

Communication between Circle and Supabase uses encrypted HTTPS/TLS connections.

Passwords must:

  • Be handled by the authentication system
  • Be securely hashed
  • Never be stored in plain text

Circle should not maintain a separate plaintext password field in its own user tables.

Database Architecture

The shared backend may store information required to operate Circle, including:

  • User accounts
  • Profile information
  • Friendships/follow relationships
  • Circle memberships
  • Circle information
  • Encrypted post metadata

Personal content should be minimized on centralized infrastructure where practical.

The database architecture should be designed to scale while maintaining:

  • Fast response times
  • Strong security
  • High reliability

Media Editing Monetization

The original free/premium editing model is also explicitly documented:

Circle Free Editing

Free users receive:

  • Basic editing
  • Crop
  • Rotate
  • Brightness
  • Contrast
  • Saturation
  • 8–12 filters/effects
  • 1 featured Circle+ filter
  • 1 featured Circle+ effect

The featured Circle+ filter and effect rotate every two weeks.

Circle+

Circle+ costs $3.99/month and may include:

  • All filters
  • All effects
  • New filters immediately when released

Circle Max

Circle Max costs $9.99/month and includes:

  • Everything in Circle+
  • AI editing tools

The exact AI editing feature set remains subject to the current Circle Max plan definition.

Free Experience Principle

The free version should remain a complete social networking experience.

Premium subscriptions should add optional creative/customization capabilities rather than paywalling Circle's core social features.

Donations

The Settings area includes a donation option where a user can:

  • Choose a custom donation amount
  • Add a message
  • Contribute directly to Circle's development

Donations are separate from the subscription plans.

38. Product Philosophy

Circle's documented product goal is to combine:

  • The communication of messaging apps
  • The community features of social networks
  • The privacy approach of modern technology platforms

The intended experience is personal, clean, and controlled by the user.

The name "Circle" represents:

  • Connection
  • Community
  • Trust
  • People coming together
